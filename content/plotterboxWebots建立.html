plotterboxWebots建立

黃俊錡41023235 所作:

黃俊錡41023235的心得

在本次 Plotter Box 專題實作中，我利用 Webots 模擬環境結合 Python 程式控制，完成一個具備旋轉關節的簡易繪圖機構。透過這次實作，我不僅學會如何建立機器人模型與關節結構，也更深入理解機構運動與程式控制之間的關係。

在建模過程中，我首先使用 Webots 建立 Robot 節點，並透過 HingeJoint 與 RotationalMotor 來模擬旋轉關節。一開始雖然馬達可以轉動，但旋轉方向卻與預期不同，甚至出現「歪著轉」的情況。後來經過反覆檢查與調整，才發現問題並不在 Python 程式，而是出在 HingeJointParameters 中的 axis 設定。這讓我了解到，在 Webots 中，關節的旋轉方向並不是由畫面上的座標軸決定，而是由關節參數中的旋轉軸所控制，這是一個非常容易忽略、但卻相當關鍵的細節。

在程式控制方面，我使用 Python 撰寫控制器，透過 motor.setPosition() 來設定關節旋轉角度，並且學會 Webots 所使用的角度單位是「弧度（rad）」而非「度（deg）」。透過將角度轉換為弧度，我成功讓關節轉動到指定角度，也更加理解實際機器人控制中數學轉換的重要性。

本次實作過程中，我也遇到不少困難，例如找不到 HingeJointParameters 的設定位置、不熟悉 Webots 介面操作，以及無法判斷旋轉方向錯誤的真正原因。然而，正是這些問題，讓我逐步培養出除錯與分析問題的能力，學會從模型結構、參數設定到程式邏輯一一檢查，而不是只單純修改程式碼。

透過 Plotter Box 專題，我體會到機械結構設計與控制程式之間密不可分的關係，也對未來在機器人控制、機構模擬與自動化系統設計有更清楚的概念。這次的經驗不僅提升了我使用 Webots 與 Python 的能力，也為後續進一步學習多關節機械手臂、運動學分析與繪圖機構控制打下良好的基礎。
